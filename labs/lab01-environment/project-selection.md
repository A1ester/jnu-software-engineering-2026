# 课程设计选题说明

正式题目：《校园社团活动管理系统》。阅读课程《软件工程概述》课件后，我理解软件工程关注开发挑战、质量属性和软件过程；开发并非只写程序，而要经历问题定义、需求开发、设计、实现、测试、运行维护。选题应能支撑这些活动。

校园社团活动有明确的问题域、学生与组织者等清晰角色，以及筹备、审核、报名、签到等真实业务流程。可以先确定必要流程，再依据调研逐步确定候补、资源、统计等扩展范围，避免一次做完所有功能。需求可以规格化并用后续 UML 建模、实现和测试验证；版本文档与阶段基线适合 Git 配置管理。多角色、状态流转、任务协作和权限归属也是有价值的软件工程问题。当前阶段仅选择和分析项目，不宣称已有系统。
