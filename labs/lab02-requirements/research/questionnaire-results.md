# 问卷正式统计分析

## 调查方式与数据版本

本次调查通过微信群发布线上问卷，由各阶段学生自愿、匿名填写，用于《校园社团活动管理系统》的需求分析。原始回收时间为2026年10月20日至21日。共回收369份；对发现的选项冲突和经历矛盾，由原填写者确认修订，项目负责人已确认所有修改均经本人逐项确认。本报告使用该修订版工作簿的“清洗后数据”表，369份全部纳入描述统计。

工作簿保留2600条修订记录，涉及353份答卷。这是修订后纳入数量，不将其表述为原始答卷零问题或原始有效率100%。此前220份和369份导出属于同一批调查的中间版本，不与本版累加为额外样本。

招募属于便利抽样。学校及微信群分布、邀请人数和未回应人数未采集，因此不计算回收率、总体抽样误差或学校间差异；结论仅描述本次受访学生。年级“其他”保留原编码，不推断具体学段。尚未完成真实访谈，问卷不包含管理中心工作人员的正式访谈意见。

## 样本与质量检查

369个答卷序号均唯一。按既定规则复查，选项互斥冲突、已定义的跨题经历矛盾、选择题编码异常和整题漏选均为0；没有整份答案完全重复的记录。提交用时为181—301秒，中位数241秒。相同网络出口不作为剔除依据。这些检查说明修订版内部一致，不替代招募和修改确认的事实记录。

默认比例为选择该选项的人数除以本表分母，保留一位小数。多选题各项比例可相加超过100%，分组间也有重叠。签到题使用参加过活动的190人为主要分母；筹备题使用参与过筹备或担任过负责人的187人；场地物资困难使用明确未选“未接触过”的243人。问卷中的“其他”“无需求”“不了解”和开放题空白保留原含义。

## 数据与复现

线上导出采用Q01～Q23；与最初Word问卷的B01、B02、Q01～Q15映射见`questionnaire.md`。公开仓库只保存汇总频数、分组分母、主题规则和脚本，不上传IP、逐人答卷或完整自由文本。本地原工作簿及修订记录保留。

```powershell
python -m pip install openpyxl
python labs/lab02-requirements/research/analyze_questionnaire.py "本地修订问卷.xlsx" --output-dir labs/lab02-requirements/research/statistics
```

输出包括`questionnaire-statistics.csv`、`open-response-coverage.csv`、`open-response-themes.csv`和`survey-summary.json`。频数CSV同时提供全体及三类经历分组，正文选用最相关的分母。源工作簿SHA-256见JSON，脚本运行前后核对文件未改变。日期统计表示原始回收时间，不将其当成后续确认修订发生的时间。
