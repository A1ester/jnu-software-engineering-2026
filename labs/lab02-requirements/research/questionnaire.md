# 模拟问卷设计

课程实验模拟问卷，面向普通学生及有社团经历者；Q01～Q15 为题号。可多选题允许多项，量表为 1（完全不符合）至 5（完全符合）。问题用于发现现状和取舍，不暗示功能必需。

| 题号 | 问题 | 题型与选项 |
|---|---|---|
| Q01 | 目前主要从哪里获知校园社团活动？ | 多选：社团群、公众号/网页、朋友、线下海报、其他 |
| Q02 | “活动信息分散，难以确认最新版本”与你经历相符的程度？ | 1～5 量表 |
| Q03 | 查找活动时最常用哪些条件？ | 多选：时间、社团、地点、主题、不筛选 |
| Q04 | 最近一次报名最耗时的步骤是什么？ | 单选：寻找入口、填写信息、确认是否成功、无明显问题、未报过名 |
| Q05 | 已报名后若不能参加，通常如何处理？ | 单选：线上取消、私信组织者、直接缺席、未遇到；开放说明原因 |
| Q06 | 满员时你更倾向哪种处理？ | 单选：候补并告知顺位、仅提示满员、推荐其他活动、无所谓 |
| Q07 | 哪类提醒对你有帮助？ | 多选：报名结果、活动临近、任务截止、无需提醒；可填期望时间 |
| Q08 | 你遇到过哪些签到问题？ | 多选：入口难找、排队、误签/代签、记录不清、没有问题/未参加 |
| Q09 | 你查看历史活动记录的主要目的？ | 单选：回顾参与、证明参与、查看反馈、几乎不看；开放原因 |
| Q10 | 对入社申请或成员管理，最需要解决什么问题？ | 多选：申请进度、成员身份、负责人交接、没有需求/不了解 |
| Q11 | 你参与筹备时如何分配任务？ | 单选：群消息、表格、专用工具、口头、未参与；开放困难 |
| Q12 | 筹备任务中哪项最容易遗漏？ | 多选：负责人、截止时间、状态、无明显遗漏/未参与 |
| Q13 | 场地或物资申请中实际遇到过什么困难？ | 多选：资源可用性、审批进度、冲突、未接触；开放说明 |
| Q14 | 活动系统中哪些信息应限制可见？ | 多选：联系方式、报名名单、签到记录、内部任务、无特别要求 |
| Q15 | 如果只先改进一件事，你会选什么？还有什么不希望系统做？ | 开放题 |
