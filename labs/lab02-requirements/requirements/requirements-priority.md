# MoSCoW 优先级与当前版本范围

调研材料用于课程需求分析练习，不代表实际校园调查。Must 构成当前课程版本的最低业务闭环，Should/Could 是后续可选范围，尚未承诺全部开发。优先级主要依据材料中的报名确认、审核、安全和筹备任务等问题确定。

| 级别 | 需求 ID 与能力 | 依据 |
|---|---|---|
| Must | FR-001～FR-014、FR-016、FR-018～FR-020、FR-032；NFR-001、003～007、009、011～014 | 基础身份/角色、社团与入社、活动创建审核发布、浏览报名取消签到、筹备任务、关键通知、备份恢复和运行日志构成可追踪闭环；Q02/Q04/Q07、三类访谈、教师 SRS 模板及完整性约束支持 |
| Should | FR-015、FR-017、FR-021～FR-026、FR-033～FR-034；NFR-002、008、010 | 候补、个人记录、待办、场地、评价、统计与社团治理是重要补充；FR-033～FR-034 来源于 2026-09-29 项目范围澄清并已纳入 requirements-v1.1 |
| Could | FR-027～FR-031 | 物资接触者少；推荐、举报、导出及可视化审计属于扩展 |
| Won't for current release | 即时聊天、在线文档、视频会议、邮箱、支付、复杂 AI 推荐、社交媒体系统 | 超出校园活动管理边界与课程规模，开放题材料也不支持扩大办公功能 |

Should 中 FR-024 场地申请涉及管理中心审批，但因 Q13 有 12/20 未接触资源申请，暂不升为 Must。NFR-002 性能阈值须在约定环境下冻结。完整逐项描述见功能/非功能需求文件。
