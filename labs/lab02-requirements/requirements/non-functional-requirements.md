# 非功能需求

均为待验证要求，不是已测结果。课程实验负载、浏览器版本、响应时间阈值等精确数值在设计/测试阶段冻结为 TBD；未冻结前不能宣称性能达标。

| ID / 类别 | 要求 | 条件与验收方式 | Priority | Source |
|---|---|---|---|---|
| NFR-001 易用性 | 学生可从公开活动列表找到报名入口，报名结果以明确状态反馈。 | 用新用户任务脚本观察“查找→报名→确认”，记录完成率与用时；目标阈值 TBD。 | Must | Q03, Q04, INT-STUDENT |
| NFR-002 性能 | 常规活动列表、详情和报名确认应在课程实验约定负载下达到响应时间目标。 | 固定数据量、并发数和环境后测 p95 响应时间；三者与阈值 TBD。 | Should | Q04, DOMAIN |
| NFR-003 可靠性 | 状态变更失败时，不得留下报名数与正式名额不一致的结果。 | 注入失败并重试，核对报名记录与容量计数；不得超额或重复。 | Must | Q06, DOMAIN |
| NFR-004 密码安全 | 账号密码不得明文保存或在日志中出现，必须使用合适的单向密码哈希。 | 检查持久化和日志样本；明文为不通过。 | Must | DOMAIN |
| NFR-005 授权安全 | 受保护操作均须核查登录状态、角色和资源归属。 | 用未登录、越权角色、其他社团负责人分别请求；均应拒绝。 | Must | INT-ADMIN, DOMAIN |
| NFR-006 输入与会话安全 | 对外输入按字段规则校验；无效或过期会话不得继续操作。 | 以空值、超长、非法状态和过期会话验证拒绝与错误反馈。 | Must | INT-ADMIN, DOMAIN |
| NFR-007 审计 | 审核、活动状态变化、成员身份变更留下操作者、时间、对象及结果。 | 执行三类操作后核对完整审计记录，普通学生不可查看。 | Must | INT-ADMIN |
| NFR-008 可维护性 | 核心业务规则与验收条件保持编号并可从 SRS 追踪到后续设计和测试。 | 评审核对 FR/BR 到设计、用例映射；设计/用例 ID 当前 TBD。 | Should | DOMAIN |
| NFR-009 可测试性 | 关键状态和错误分支可在受控测试数据下重复触发。 | 后续测试环境重复执行报名、取消、审核、签到场景并比较结果。 | Must | DOMAIN |
| NFR-010 兼容性 | Web 界面应支持课程约定的桌面浏览器，关键流程无阻断。 | 浏览器与版本清单 TBD；逐一执行查找、报名、审核任务。 | Should | Q03, DOMAIN |
| NFR-011 数据完整性 | 重复提交报名、取消、审核请求不产生重复有效记录或互相矛盾状态。 | 对相同请求重复/并发提交，核对唯一性和最终状态。 | Must | Q04, INT-ADMIN, DOMAIN |
| NFR-012 隐私 | 联系方式、完整报名名单、个人签到记录仅向有业务需要的授权用户展示。 | 分别用学生、其他社团负责人、所属负责人、管理员账户核对可见字段。 | Must | Q14, INT-STUDENT, INT-ADMIN |

性能目标与兼容清单的 TBD 是待冻结的验收参数，不代表可以省略验证。
