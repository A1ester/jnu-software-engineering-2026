# 非功能需求

均为待验证要求，不是已测结果。课程实验负载、浏览器版本、响应时间阈值等精确数值在设计/测试阶段冻结为 TBD；未冻结前不能宣称性能达标。

| ID / 类别 | 要求 | 条件与验收方式 | Priority | Source |
|---|---|---|---|---|
| NFR-001 易用性 | 学生可从公开活动列表找到报名入口，报名结果以明确状态反馈。 | 用新用户任务脚本观察“查找→报名→确认”，记录完成率与用时；目标阈值 TBD。 | Must | Q03, Q04, INT-STUDENT |
| NFR-002 性能 | 常规活动列表、详情和报名确认应在课程实验约定负载下达到响应时间目标。 | 固定数据量、并发数和环境后测 p95 响应时间；三者与阈值 TBD（待教师确认），测试前冻结。 | Should | Q04, 领域约束 |
| NFR-003 可靠性 | 状态变更失败时，不得留下报名数与正式名额不一致的结果。 | 注入失败并重试，核对报名记录与容量计数；不得超额或重复。 | Must | Q06, 领域约束 |
| NFR-004 密码安全 | 账号密码不得明文保存或在日志中出现，应使用后续安全设计中确定的单向密码哈希方案。 | 检查持久化和日志样本；出现明文密码即不通过，具体算法与参数在安全设计中确定。 | Must | 领域约束 |
| NFR-005 授权安全 | 受保护操作均须核查登录状态、角色和资源归属。 | 用未登录、越权角色、其他社团负责人分别请求；均应拒绝。 | Must | INT-ADMIN, 领域约束 |
| NFR-006 输入与会话安全 | 对外输入应按已定义的字段约束校验；无效或过期会话不得继续操作。 | 以空值、超长、非法状态和过期会话验证拒绝与错误反馈；字段长度和格式在设计前冻结。 | Must | INT-ADMIN, 领域约束 |
| NFR-007 审计 | 审核、活动状态变化、成员身份变更留下操作者、时间、对象及结果。 | 执行三类操作后核对完整审计记录，普通学生不可查看。 | Must | INT-ADMIN |
| NFR-008 可维护性 | 核心业务规则与验收条件保持编号并可从 SRS 追踪到后续设计和测试。 | 评审核对 FR/BR 到设计、测试用例的映射；设计与测试用例 ID 当前为 TBD。 | Should | 领域约束 |
| NFR-009 可测试性 | 关键状态和错误分支可在受控测试数据下重复触发。 | 后续测试环境重复执行报名、取消、审核、签到场景并比较结果。 | Must | 领域约束 |
| NFR-010 兼容性 | Web 界面应支持课程约定的桌面浏览器，关键流程无阻断。 | 浏览器与版本清单为 TBD；冻结后逐一执行查找、报名、审核任务。 | Should | Q03, 领域约束 |
| NFR-011 数据完整性 | 重复提交报名、取消、审核请求不产生重复有效记录或互相矛盾状态。 | 对相同请求重复或并发提交，核对唯一性和最终状态。 | Must | Q04, INT-ADMIN, 领域约束 |
| NFR-012 隐私 | 联系方式、完整报名名单、个人签到记录仅向有业务需要的授权用户展示。 | 分别用普通学生、其他社团负责人、所属负责人、管理中心工作人员账户核对可见字段。 | Must | Q14, INT-STUDENT, INT-ADMIN |
| NFR-013 备份与恢复 | 系统应支持对账号、社团、活动、报名、任务、审核和审计信息进行备份与恢复；备份周期、保留期和恢复时间目标为 TBD（待教师确认）。 | 在约定测试环境中生成备份、恢复到独立环境，并核对核心记录数量、关联关系和关键状态；具体目标在测试计划编制前冻结。 | Must | 教师 SRS 模板, 领域约束 |
| NFR-014 系统日志 | 系统应记录登录失败、未授权访问、系统错误和后台任务失败等运行事件，包含时间、事件类型、结果及必要的关联对象；日志不得记录明文密码。日志保留期为 TBD（待教师确认），仅经授权的管理中心工作人员可查看。 | 分别触发四类事件并核对日志字段、访问控制和敏感信息遮盖；保留策略在测试计划编制前冻结。 | Must | 教师 SRS 模板, INT-ADMIN, 领域约束 |

性能目标与兼容清单的 TBD 是待冻结的验收参数，不代表可以省略验证。
