# 校园社团活动管理系统

暨南大学《软件工程实验》课程设计。项目面向学校社团管理中心、学生社团和普通学生，覆盖活动筹备、审核发布、报名签到与协作。

## 当前资料

- 实验1：环境搭建、Hello World、选题和初步计划。
- 实验2：通过微信群发布线上问卷，369份答卷经原填写者逐项确认修订后纳入[正式统计](labs/lab02-requirements/research/questionnaire-results.md)，形成requirements-v1.2需求说明。
- 需求包含34项功能需求、14项非功能需求、12项业务规则；题号统一为线上Q01～Q23，来源可追踪。

调查通过微信群自愿招募学生，结论描述本次便利样本。公开仓库提供汇总频数、分组分母和复现脚本，逐人答卷、IP与完整自由文本保留本地。

## 开发版本

可运行课程演示版本及相应设计、测试记录位于[feat/core-platform分支](https://github.com/A1ester/jnu-software-engineering-2026/tree/feat/core-platform)。该分支包含运行说明、设计文档和已执行的测试记录。用户体验、负载性能及完整兼容性仍待验证，学校正式业务制度尚待核实。
