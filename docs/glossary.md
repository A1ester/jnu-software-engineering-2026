# 术语表

| 术语 | 中文定义 |
|---|---|
| Activity | 活动；由社团发起、有时间、地点与状态的校园事项 |
| Club | 社团；具有成员及负责人的校园组织 |
| Registration | 报名；学生申请参加某一活动的记录 |
| Waitlist | 候补；正式名额满时按顺序等待转正的记录 |
| Check-in | 签到；对已获正式报名资格者的到场确认 |
| Task | 筹备任务；归属活动、指定负责人和截止时间的工作项 |
| Todo | 待办；当前用户需要处理的事项汇总 |
| Notification | 通知；与状态变化有关的站内消息 |
| Approval | 审核；学校社团管理中心工作人员对社团备案、活动或资源申请作出通过或驳回决定 |
| Role | 角色；普通学生、社团成员、社团负责人或学校社团管理中心工作人员等职责集合 |
| Permission | 权限；在角色和资源归属限制下可执行的操作 |
| 学校社团管理中心工作人员 | 学校层面的业务管理角色，负责跨社团审核、治理、资源协调、统计与审计；不是服务器、数据库或运维意义上的 System Administrator |
| Activity Status | 活动状态；Draft、Submitted、Approved、Rejected、Published、RegistrationOpen、RegistrationClosed、InProgress、Finished、Archived 或 Cancelled |
| MoSCoW | 需求优先级方法；分为 Must、Should、Could 和 Won't for current release |
| TBD | 待确认；尚需在后续评审、设计或测试准备阶段确定的内容 |
| 领域约束 | 由业务完整性、安全性或系统边界直接产生的需求来源 |
