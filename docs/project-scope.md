# 项目候选范围

本页是实验 1 的候选业务域，最终版本范围以实验 2 的模拟调研和 MoSCoW 结论为准，不表示全部必须实现。

| 域 | 候选内容 |
|---|---|
| A Identity & Access | 用户、角色、权限 |
| B Club | 社团信息、成员、入社申请 |
| C Activity | 活动创建、审核、发布和生命周期 |
| D Registration | 报名、取消、候补、签到 |
| E Collaboration | 筹备任务、负责人、截止时间、状态 |
| F Resource | 场地和物资申请 |
| G Notification | 通知、提醒、待办 |
| H Feedback & Analytics | 评价、个人活动记录、统计 |
| I Governance | 平台审核、举报、审计 |

借鉴协同管理中的负责人、截止时间、状态和待办概念，但不复制办公套件。
