## CR-002 三层角色体系与平台定位澄清

| 项目 | 内容 |
|---|---|
| 变更编号 | CR-002 |
| 日期 | 2026-09-29 |
| 来源 | 课程项目范围确认 / 项目负责人确认 |
| 变更原因 | 进一步明确系统同时面向学校社团管理中心、学生社团和普通学生，需要区分平台治理、社团运营和学生参与三个业务层次 |
| 影响范围 | 产品定位、用户角色、用例模型、Product Backlog、社团治理需求、权限范围、概念领域模型 |
| 处理原则 | 保留 FR-001～FR-032；新增 FR-033、FR-034；不移动旧 baseline；本次澄清纳入 `requirements-v1.1` |
| 状态 | 已纳入 requirements-v1.1 |

### 处理内容

1. 正式项目名称保持《校园社团活动管理系统》，产品定位统一为面向学校社团管理中心、学生社团和普通学生的校园社团综合管理与协同平台。
2. 学校社团管理中心工作人员作为学校层面的业务管理角色，负责跨社团审核、治理、资源审批、统计和审计，不表示技术运维权限。
3. 社团成员和社团负责人仍属于学生用户，在具体社团上下文中获得附加角色和权限。
4. 新增 FR-033 社团备案与审核、FR-034 社团状态及负责人变更管理，并更新需求、模型、Backlog、迭代计划与追踪矩阵。
5. 本变更来自课程项目范围澄清，并已完成关联文档的一致性检查。
