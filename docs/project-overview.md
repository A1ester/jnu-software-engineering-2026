# 项目概述

正式题目：《校园社团活动管理系统》。产品定位为“面向学校社团管理中心、学生社团和普通学生的校园社团综合管理与协同平台”。学校社团管理中心承担跨社团治理、活动审核、资源协调、统计与审计；各学生社团负责成员、活动、筹备、报名签到和资源申请；普通学生负责社团发现、入社申请、活动参与和个人记录。访客可浏览公开信息，但不构成独立业务层级。

通过微信群回收的369份问卷，经原填写者逐项确认修订后用于需求分析。调查反映了报名填写与确认、签到记录、任务责任与期限、资源审批等方面的改进需求。对于活动信息分散，343名可判断者中相符者占37.6%，不相符者占39.9%，样本未形成多数共识。系统据此提供统一活动入口、明确的办理状态和按职责划分的操作权限。

系统范围包括社团及其活动、成员、场地、通知与管理，不含聊天、在线文档、视频会议、邮箱或支付。需求说明版本为requirements-v1.2。`feat/core-platform`分支已实现核心业务及资源、反馈和统计等既定功能，并完成独立数据库和浏览器流程验证。后续工作包括使用体验、非功能目标验证和正式部署准备。
