# 项目概述

正式题目：《校园社团活动管理系统》。产品定位为“面向学校社团管理中心、学生社团和普通学生的校园社团综合管理与协同平台”。学校社团管理中心承担跨社团治理、活动审核、资源协调、统计与审计；各学生社团负责成员、活动、筹备、报名签到和资源申请；普通学生负责社团发现、入社申请、活动参与和个人记录。访客可浏览公开信息，但不构成独立业务层级。

当前主要问题是活动信息分散、报名与签到记录不一致、组织任务缺少明确负责人和期限、审核过程难追踪。系统边界为校园社团及其活动、成员、场地、通知与治理；不包含聊天、在线文档、视频会议、邮箱或支付。预期价值是降低信息遗漏、重复处理和权限混乱。requirements-v1.1 需求分析已完成；当前已实现核心业务及资源、反馈和统计等既定功能，完成独立数据库与浏览器流程验证。后续工作主要是使用体验、非功能目标验证和正式部署准备。
